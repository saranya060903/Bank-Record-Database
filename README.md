 🏦 Bank Database Management System

 📌 Project Overview
A MySQL-based project designed to manage banking information, including branches, customers, accounts, loans, employees, transactions, ATMs, and cards.

 🎯 Project Objectives
- Store and manage banking information in a database.
- Retrieve customer, account, and loan details using SQL queries.
- View customer and branch-related information.
- Analyze customer counts and loan amounts using aggregate functions.

 ✨ Key Features
- 🏢 Manage bank branch details.
- 👥 Store customer information.
- 💳 Manage account balances and card details.
- 💰 Store loan amounts and interest rates.
- 👨‍💼 Maintain employee details.
- 🔄 Retrieve deposit and withdrawal transactions.
- 🏧 Store ATM locations.
- 🔗 Retrieve related information using JOIN operations.
- 📊 Count customers per branch using GROUP BY.
- 📈 Calculate total loan amounts using SUM.
- 🔍 Filter data using WHERE, LIKE, and BETWEEN.
- ⚖️ Categorize account balances using CASE.
- 👁️ Create and retrieve data from a VIEW.
- ⚙️ Use a stored procedure to retrieve customer details by branch.

🛠️ Technologies Used

- 💻 SQL
